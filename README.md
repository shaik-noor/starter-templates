# Starter Templates

Standalone starter projects you can clone or fork individually. You do not need to download this collection repository to use a template.

## Available templates

| Template | Description | Repository |
| --- | --- | --- |
| SvelteKit + Supabase + shadcn-svelte | SvelteKit 5, TypeScript, Tailwind CSS, shadcn-svelte, Supabase Auth and PostgreSQL, with a local SQLite fallback | [starter-sveltekit-supabase-shadcn](https://github.com/shaik-noor/starter-sveltekit-supabase-shadcn) |

## Clone one template

Clone the standalone repository directly:

```bash
git clone https://github.com/shaik-noor/starter-sveltekit-supabase-shadcn.git
cd starter-sveltekit-supabase-shadcn
npm install
```

See that template's README for environment setup and instructions to run it.

## Fork one template

With the GitHub CLI installed and authenticated:

```bash
gh repo fork shaik-noor/starter-sveltekit-supabase-shadcn --clone
```

Or open the template's repository on GitHub, select **Fork**, then clone your fork:

```bash
git clone https://github.com/YOUR-USERNAME/starter-sveltekit-supabase-shadcn.git
cd starter-sveltekit-supabase-shadcn
```

## Clone the full collection

To browse all templates together, clone this repository:

```bash
git clone https://github.com/shaik-noor/starter-templates.git
```
